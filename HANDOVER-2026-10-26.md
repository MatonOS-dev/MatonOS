## Architecture (decided, all in memory)
- **EROFS single images**: one image per package (runtime IDs: one image with a dir per branch — branch merging is
  planned, not built). Stubs mount eagerly via **matonos-erofsd** (in the image, frozen API): it validates (pinned stub
  cert, re-shared by the subsystem each boot; the subsystem itself may also mount), **init** does the mount through
  `matonos.erofs.*` property triggers (only init may mount, domain.te neverallow). Mounts at `/mnt/matonos/<owner uid>/<n>`,
  shared, swept when unused (token fix 900e558) or when the APK is replaced.
- **Proxy**: prefix swap of package targets (and each package's PHYSICAL deployment `files/`) to the mount; native
  stat/open/getdents after the swap. Targets computed at LAUNCH from the launching app's runtime (e941f5b); duplicate
  targets are a loud error. Flatpak extension version selection (2398e0a).
- **fds**: exact reserve of 18 fds at the top of the real soft limit; only close-sweep skip + move-on-dup guards; one SysV
  IPC arena memfd; EROFS dir lock = in-process mutex (cross-process listing race accepted).
- **Install**: streaming mkfs (LZ4HC 9, 56% of native), parallel builds/commits, Locale = device languages only
  (`--subpath`), per-phase timing logs. Cold Tux Racer install 674 s → 173 s.
- **No job caps** anywhere (rule in both AGENTS.md); builds default to nproc (zram makes it safe).
- **Builds and VM tests never run at the same time** (user).
