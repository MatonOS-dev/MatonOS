## Lessons tonight
- Trace numbers in `v3 trap ours N r` are proxy op ids, not syscall numbers (27=close, 135=ioctl, 212=openat, 35=dup2).
- Proxy hardlink emulation = 01600 marker files + `.v3-inodes` store; anything reading app trees RAW (outside the
  proxy) must resolve them (`PlaceholderFiles`; install root now carries `.v3-store-root`).
- Binaries the stub runs directly (fsck/mkfs) face Android's app seccomp: only bionic-allowed syscalls.
- Symbolize loader crashes: pc − map start + map offset = file offset → vaddr via `readelf -lW`, then
  `addr2line` on `~/matonos/build/main-out/deps/linux-subsystem-app/loader/libmatonos-v3-loader.so`.
