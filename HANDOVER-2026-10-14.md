## Lessons

- **Agent VMs headless only.** Use `MATON_QEMU_HEADLESS=1`. A GTK window with the host display off ticks virgl fences at 1 s.
- **The Flatpak wrapper is a path gate** (memory `flatpak-wrapper-path-gate`).
  - Any `/data/linux-app` layout or uid change must update `linux/flatpak/flatpak-env-wrapper.c` and `linux-paths.h`.
  - Exit 127 with empty output means the wrapper rejected the call.
  - Rebuild with `tools/build-flatpak-helpers.sh`.
- **Hot-patch labels:**
  - loader / APK: `system_file`, bound in Zygote's namespace;
  - linuxd: tmpfs + `matonos_linuxd_exec`;
  - APEX wrapper: tmpfs + `system_file`, bound over `/apex/com.matonos.flatpak/bin/...`.
- **Codex quirks:**
  - The OpenAI filter flagged a brief with crash-address wording; neutral wording passed.
  - The usage limit hit once; resume with a "RESUME" brief.

## How to test fast

- **Builds:** `MATON_BUILD_COORDINATOR=1 tools/build.sh -K -M -j 16` (20–40 min).
  - Policy only: `-m selinux_policy`.
  - linuxd only: `-m matonos-linuxd`.
  - Host APK: `bash linux/compat-proxy/build-android.sh && MATON_APPS_FORCE=1 MATON_APPS_ONLY=matonos-wayland-host tools/build-apps.sh`.
  - Wrapper/store helpers: `bash tools/build-flatpak-helpers.sh`.
- **VM:** `MATON_QEMU_HEADLESS=1 tools/run-qemu-live.sh -i ~/matonos/vm/claude/live.img -g virgl -a 5556`, then `setprop persist.vendor.maton.sleep_idle_s 0`.
- **Install:** `MATON_ADB_SERIAL=127.0.0.1:5556 install/tools/test-flatpak.sh --install app/<id>/x86_64/stable`.
- **Real key events** (scan codes): `sendevent /dev/input/event1 1 <KEY_*> 1/0`.
- **Mouse:** under pointer capture use the relative device `/dev/input/event4`.
- **Network for a test:** write `[Context]\nshared=network;` to `$(readlink -f /data/linux-app/install/<uid>)/overrides/<app-id>`, then remove it.
