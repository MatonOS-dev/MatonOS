## Runtime pruning design (REJECTED: shared stock install)
A shared stock install was rejected: `install/<uid>` exists so Android attributes app size to the app
UID (ownership-based). App files must stay in install/<uid>, owned by that UID.
User design (adopted): linuxd db /data/matonos/linux/runtime/refs-<android_user>.json mapping full ref ->
[app UIDs]. Publish adds, uninstall removes + uninstalls refs with no UIDs (replaces --unused), boot reconcile
drops dead UIDs, NO migration/seeding (user: never deployed) — missing db = empty, fail closed only on malformed db. codex `runtime-refdb` started
