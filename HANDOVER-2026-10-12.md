## Big picture: Linux layer v3

v2 (linuxd → privileged `flatpak run` → real bwrap → `matonos_bwrap`/`flatpak_run`/
`app_launch`/`linux_app` domains) is **dead**: it needed stock-neverallow exceptions
(mounts, noatsecure, SysV ptrace, DNS fd passing). User: "v2 failed, it's dead" — delete it
when v3 is integrated, no fallback switch.

**v3 = Wine-style in-process syscall proxy** (`linux/compat-proxy/`, README there).
A freestanding loader runs Linux (glibc *and* bionic) ELFs inside the stub app's own process:
- Android's app filter returns `SECCOMP_RET_TRAP` → our guarded SIGSYS handler emulates,
  translates (legacy x86_64 calls → `*at`/`dup3`…) or returns ENOSYS.
- Our stacked filter traps only exec, path calls, signal controls, namespace/mount calls.
  Everything else (GPU ioctls, futex, I/O) goes straight to the kernel.
- exec is in-process (no `execve` of data files); bwrap's namespaces/mounts/pivot_root are a
  per-process virtual mount table; `flatpak run` and bwrap run unmodified on top.
- SIGSYS demuxed by `si_code` (SYS_SECCOMP ours, SYS_USER_DISPATCH → app, e.g. Wine);
  SIGSYS kept deliverable (sigprocmask, SA_RESETHAND, sigaltstack guarded).
- Security boundary = the stub's Android UID + untrusted_app SELinux (user: "far better than
  standard flatpak"); path translation is compatibility only.

## Decisions (user, 2026-10-12) — details in memory `compat-proxy` / `per-user-linux-layout`

- **Enforcing is the default.** Stop passing `MATON_SELINUX_PERMISSIVE=1` (old SF bootloop reason
  is gone). Zygote skips the app seccomp filter when permissive — test v3 on enforcing images.
- **Syscalls:** if our kernel supports it and Android doesn't block it → pass through.
  Allowed natively: the bionic-patch seven. Emulate IPC: SysV, POSIX mq, keyrings. Emulate if
  needed: NUMA, cachestat, statmount/listmount/listns. Getters faked/setters refused: lsm_*,
  file_*attr. ENOSYS: io_uring, memfd_secret, map_shadow_stack, fanotify, modify_ldt (16-bit →
  DOSBox; revisit only if Wine WoW64 needs it), pkey_*, kcmp, process_mrelease, remap_file_pages,
  ustat. Keep `CONFIG_IO_URING=y` (Virtual A/B snapuserd uses ublk).
- **Layout mirrors ART/PackageManager:** Flatpak deployments + runtimes installed once,
  system-wide in **`/data/linux-app/`** (sibling of `/data/app`, never inside it), linuxd-owned,
  read-only to apps, keyed by app id (`uid % 100000`); stub enabled per user
  (install-existing). Linux HOME = **`/data/user/<u>/<stub pkg>/home/`** (stub mkdirs it, no
  patch), cache → app cache dir. Per-user install decision of 2026-10-11 is superseded;
  `org.matonos.linuxruntimes` retires; vold patch and `data-exec-exempt-domain` patch retire.
- Borrowed from ART: versioned deployment dirs + atomic swap + GC after restart; fs-verity on
  deployments; linuxd install-time caches (ldconfig, fonts, icons, schemas); runtimes and runtime
  extensions versioned + refcounted; app extensions live/die with the app (optional ones on
  demand, Locale trimmed); per-app storage accounting; stubs `allowBackup=false`. Per-app compat
  flags: skip until needed.
- Updates while running: **defer** like Linux (running instance keeps the old dir).
- Uninstall for one user removes that user's data; code goes when no user has the stub.
- Background: map Linux behaviour onto Android (window → visible; audio → media FGS; downloads
  → data-sync FGS; else freezable). Design brief later.
- Hardware: webcams → dummy device backed by Camera2 + CAMERA permission; ALSA via PipeWire
  plugin; HID/USB low priority.
- sleepd **replaces** Android sleep; Android suspend must never run; installs hold a wake lock.

## Gotchas learned today

- VM sleeps: sleepd idle-suspends a test VM mid-install → set `persist.vendor.maton.sleep_idle_s 0`.
  After s2idle resume, virtio-gpu fences hang (SF RenderEngine) — investigated, not fixed.
- Permissive VM = no app seccomp filter at all. For real-filter tests: `setenforce 1;
  setprop ctl.restart zygote`; dump with the PTRACE_SECCOMP_GET_FILTER tool (scratchpad
  `dumpfilter.c`, also described in memory).
- `adb root` makes the device "offline"; loop `adb disconnect/connect` until `id -u` = 0.
- Full Soong re-analysis can exceed RAM (23 GB) and thrash (~28 GB swap, no progress): close the
  VM before building; incremental builds are fine.
- codex: don't `--add-dir` AOSP projects whose `.git` is a symlink (sandbox fails); reading
  them needs no flag. codex's sandbox can't reach adb — the coordinator runs VM stages.
- New preflight rule: AOSP patches need an `APPROVED_PATCHES` entry (zero-patches rule).
