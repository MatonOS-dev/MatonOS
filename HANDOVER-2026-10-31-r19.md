## Findings

- Zygote SIGTRAP / GPU launch error 1002: the GLX forwarder initialised EGL in the CEF zygote, Mesa started a
  `disk$0` thread, Chromium's single-thread check failed. Fixed by the three forwarder commits.
- "Timed out waiting for webhelper init" (logged the same second): the portal runs inside the app view, so Flatpak's
  per-app /dev/shm reuse check fails there and each Spawn child got a nested `flatpak-<app>-XXXXXX` dir. Client and
  webhelper never met on `u10137-Shm_*`. `--device=shm` (emulated, stub-private dir; upstream Steam has
  `--device=all`) propagates via `.flatpak-info` extra-args.
- **Next blocker:** Steam's `WebUITransport` verifies each loopback websocket with
  `lsof -P -F upnR -i TCP@127.0.0.1:<port>`; SELinux denies `/proc/<pid>/net/tcp` (`proc_net_tcp_udp`) to
  untrusted_app, lsof exits 1, "Connection rejected", UI stays disconnected.
